 	Gerador de Currículos - Sistema Web
Descrição do Projeto
Sistema web desenvolvido em PHP para criação e geração de currículos profissionais. O projeto permite aos usuários preencher um formulário com dados pessoais, experiências profissionais, formação acadêmica e habilidades, gerando um currículo formatado que é armazenado no servidor.

Objetivos
-Desenvolver uma aplicação web completa utilizando tecnologias web modernas
-Implementar funcionalidades de frontend e backend integradas
-Permitir a criação dinâmica de campos no formulário
-Armazenar os dados no servidor de forma organizada
-Gerar currículos em formato visualmente atraente

Tecnologias Utilizadas

 Frontend
- **HTML5** - Estruturação da página
- **CSS3** - Estilização e design responsivo
- **JavaScript** - Interatividade e dinamismo
- **Bootstrap 5** - Framework para componentes UI

Backend
- **PHP** - Processamento do servidor e lógica de negócio
- **Sistema de Arquivos** - Armazenamento local dos currículos
